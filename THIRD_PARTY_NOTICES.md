# Third-party pronunciation data

The compact IPA mapping in `assets/js/pronunciation-data.js` contains only entries required by this project and is generated from the following open datasets.

## Britfone 3.0.1 — UK IPA

- Project: https://github.com/JoseLlarena/Britfone
- Copyright © 2017 Jose Llarena
- License: MIT

## ipa-dict — US IPA

- Project: https://github.com/open-dict-data/ipa-dict
- Copyright © 2016 dohliam
- English (General American) data is based on the MIT-licensed `cmudict-ipa` dataset.
- License: MIT, subject to the upstream project's third-party data notices.

Both datasets are provided without warranty. Cambridge Dictionary data is not copied into this repository. The interface only provides outbound links so learners can independently verify a word on Cambridge Dictionary.
